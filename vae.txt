```python
def encode(self, pixel_samples):
    # STEP 1: Input Validation and Preprocessing
    self.throw_exception_if_invalid()
    pixel_samples = self.vae_encode_crop_pixels(pixel_samples)
    pixel_samples = pixel_samples.movedim(-1, 1)
    
    # STEP 2: Memory Management and Batching
    memory_used = self.memory_used_encode(pixel_samples.shape, self.vae_dtype)
    model_management.load_models_gpu([self.patcher], memory_required=memory_used)
    batch_number = int(free_memory / max(1, memory_used))
    
    # STEP 3: Core Neural Network Encoding (THE CRITICAL OPERATION)
    for x in range(0, pixel_samples.shape[0], batch_number):
        pixels_in = self.process_input(pixel_samples[x:x + batch_number])
        out = self.first_stage_model.encode(pixels_in)  # ← HEART OF OPERATION
        samples[x:x + batch_number] = out
    
    return samples
```

### KEY PREPROCESSING OPERATIONS

**Pixel Cropping (vae_encode_crop_pixels - lines 506-515)**
```python
def vae_encode_crop_pixels(self, pixels):
    downscale_ratio = self.spacial_compression_encode()  # Usually 8
    dims = pixels.shape[1:-1]  # Get spatial dimensions
    for d in range(len(dims)):
        x = (dims[d] // downscale_ratio) * downscale_ratio
        x_offset = (dims[d] % downscale_ratio) // 2
        if x != dims[d]:
            pixels = pixels.narrow(d + 1, x_offset, x)
    return pixels
```
- **Purpose**: Ensure dimensions are multiples of downscale_ratio (8)
- **Example**: 835×483 → 832×480 (center-cropped to nearest 8-pixel boundary)

**Input Normalization (line 282)**
```python
self.process_input = lambda image: image * 2.0 - 1.0
```
- **Input Range**: [0.0, 1.0] (ComfyUI normalized RGB)
- **Output Range**: [-1.0, 1.0] (VAE training range)
- **Critical**: Neural networks trained on this specific range

**Step 5 Dual Encoding Memory Impact:**
```
WanVaceToVideo calls VAE.encode() TWICE per video:
1. inactive = vae.encode(inactive_frames)  # 37 frames
2. reactive = vae.encode(reactive_frames)  # 37 frames

Total VAE.encode() calls: 3 (reference_image + inactive + reactive)
Peak memory: During reactive encoding (largest tensor)
Memory per call: 37 × 832 × 480 × 1767 × 4 bytes ≈ 2.4 GB
```

**What Happens Inside:**
1. **Encoder Architecture**: Multi-layer convolutional neural network
2. **Spatial Downsampling**: Progressive 2×2 downsampling (8x total)
3. **Feature Extraction**: RGB → rich latent features
4. **Attention Layers**: Spatial relationships (in advanced VAEs)
5. **Latent Projection**: Final layer projects to latent_channels

**Input/Output Transformation:**
```
INPUT:  [batch, 3, 832, 480] RGB tensor, range [-1, 1]
OUTPUT: [batch, latent_channels, 104, 60] latent tensor
- Spatial compression: 8x (832×480 → 104×60)
- Channel expansion: 3 → latent_channels (4, 8, or 16)
- Data compression: ~64x total reduction
- Information preservation: Decoder can reconstruct original
```
